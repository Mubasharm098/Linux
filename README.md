## 💻 Basic Linux Commands

### 1. Navigation

```bash
pwd
ls
ls -la
cd /home
cd ..
```

### 2. File and Directory Management

```bash
mkdir practice
touch notes.txt
cp notes.txt backup.txt
mv notes.txt linux-notes.txt
cat linux-notes.txt
rm backup.txt
```

### 3. System Information

```bash
whoami
uname -a
hostname
uptime
free -h
df -h
```

### 4. Process Management

```bash
ps aux
top
pgrep bash
```

### 5. Search and Log Analysis

```bash
grep "error" /var/log/syslog
find . -name "*.txt"
```

Note: Log file locations and permissions vary by Linux distribution.
